# Number

## `Int`

### Properties

- `isNegative`

```dart
int number = -10;
print(number.isNegative); // Output: true
```

### Methods

- `abs()`

```dart
int number = -10;
print(number.abs()); // Output: 10
```

- `ceil()`

```dart
int number = 9.4;
print(number.ceil()); // Output: 10
```

- `floor()`

```dart
int number = 9.4;
print(number.floor()); // Output: 9
```

- `truncate()`

```dart
int number = -10.3;
print(number.truncate()); // Output: -10
```

- `toInt()`

```dart
int number = 10.00;
print(number.toInt()); // Output: 10
```

- `toDouble()`

```dart
int number = 10;
print(number.toDouble()); // Output: 10.00
```
